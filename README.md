# 🏥 Hospital Management System

A modern, responsive **Hospital Management Web Application** built using **HTML5, CSS3, and JavaScript**. The application provides patients with an easy and user-friendly interface to explore hospital services, search for doctors, book appointments, access laboratory information, and find emergency contact details.

---

## 📖 Overview

The **Hospital Management System** is a frontend web application designed to simplify and improve access to essential hospital services.

The system provides separate pages for:

* 👨‍⚕️ Doctor search
* 📅 Appointment booking
* 🏥 Hospital departments
* 🧪 Laboratory services
* 💊 Pharmacy information
* 🚑 Emergency services
* 📍 Hospital location and Google Maps integration
* 📞 Contact information

The application is designed with a **responsive user interface**, making it accessible on desktops, tablets, and mobile devices.
