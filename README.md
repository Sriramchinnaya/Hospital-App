🏥 Hospital Management System
A modern and responsive Hospital Management Web Application built using HTML, CSS, and JavaScript.

📖 Overview
The Hospital Management System is a web application designed to simplify hospital services for patients. Users can search for doctors, book appointments, explore hospital departments, access laboratory services, and find emergency contact information through an easy-to-use interface.

✨ Features
🏠 Home Page
👨‍⚕️ Doctor Search
📅 Appointment Booking
🏥 Hospital Departments
🧪 Laboratory Services
💊 Pharmacy Information
🚑 Emergency Services
📍 Google Maps Integration
📞 Contact Us Page
